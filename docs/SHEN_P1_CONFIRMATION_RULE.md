运行入口：`scripts/launch_shen_evidence.py --stage p1 --matrix configs/shen_evidence/confirmation_matrix.json --smoke-dir outputs/shen_evidence/p0_20261012/four_gpu_smoke_v2 --output outputs/shen_evidence/p1_confirmation`。

## 优化停滞排查（首筛之后登记）

首筛中 Full IQ/RTL 与 strict IB/N210 的训练、验证同时接近机会水平，而其他输入已学习到分类信号。为避免把单一配方的优化停滞误作输入缺乏信息，增加第二个统一候选 lr=3e-4，四种输入、两台接收机都使用相同预算/30epoch/早停，不仅为失败项调参。保留 lr=1e-3 的全部结果。

在两个候选均完成后，各输入/接收机按 seed20261012 的 Day2 全集 Macro-F1 选择配方并冻结，另外两seed不再次调参；所有候选和所选配方公开。若主基线仍停滞，明确标作当前实现/配方下的下界，不能判定表示无设备信息。三seed汇总只计每种输入每台所选配方，不把两个学习率的同一seed当成两个随机重复。
