# VIRP-v1：预登记执行规则

本文件与 `configs/virp/v1_registration.json`、`.seal.json` 在新实验信号结果前共同冻结。用户原文保存在 `USER_RULES_20261012.txt`，其 SHA256 纳入登记。V0 脚本、扰动实现及原 CIS 前端的代码 SHA256 同时封存。运行拒绝任何注册或封存代码修改，输出目录必须不存在。

用户指定顺序：V0 → B0–B4 两折单 seed → 三 seed 源域确认 → 冻结后 Shen 开发及 OSU 验证。任一硬关口失败，停止当前候选方法。失败后不改幅度、基函数、阈值、STFT 或损失权重，不用新模块补救同一次实验。

## 原始数据和量纲

沿用 G1 十台源 RX、每 TX/RX 200 包及种子 20261012 的原始行索引，共 20,000 包。重新对原始 HDF5 全文件 SHA256 校验；从 float64 的 I/Q 重建 complex128，不使用 float32 缓存 IQ 做新机制测量。禁止读取四台开发 RX 和六台历史锁定 RX 的信号。每个文件仅以只读模式打开并登记。

固定两折沿用 G1 的接收机分组。每折只用其五台拟合源 RX 的 clean CIS 估计一个 population SD，并只用这些 RX 构造扰动；另外五台属于源留出审计对象，其统计不参与这一折拟合。

保持历史 Full CIS：全 IQ 不删频带；128 点矩形 STFT、64 点 hop、crop_ratio .3，得到 52×126 的相邻帧谱功率商。代码是 `log10(power ratio)`，用户公式是其十倍 dB 值。分子差值和 σ 同比例变化，故标准化 δ 完全等价。不得更改复数 STFT 加入的 1e-12 或静默裁剪极端值。

## 第一个且最高优先级的 V0 关口

采用六个固定周期平滑基函数：归一化 FFT 频率上 harmonics 1、2、3 的 cos 和 sin。类别均衡后，计算源 RX 的 packet-RMS-normalized IQ 的平均自然 log 幅度谱。donor-source 差异去掉全频均值、投影到固定六维基；若峰值超过 ±3 dB，只同比缩小全曲线，不逐频点截断，也不将较弱差异放大到上限。

每包恰好检查所在拟合折内的四个其他 RX donor，强度固定为 1。全包 FFT 乘 `exp(log_response)` 后 IFFT；保持零相位。名称为 frequency-response-inspired spectral augmentation / source-observed capture-chain style，不声称因果接收机硬件仿真。

每包主 δ 为四个 donor δ 的中位数，不挑选最有效扰动。每折都要求：

|用户指定关口|标准|
|---|---|
|源包 median δ|≥0.10|
|源包 δ≥0.05 覆盖率|≥80%|
|全部包—扰动实现 δ 的 q95|≤1.0|
|NaN/Inf|0|
|每频点响应|±3 dB 以内|
|全部包—扰动实现的最佳复标量归一化 IQ 相关性|≥0.98|

零扰动 FFT/IFFT 与恒定全频 +3 dB 均用完整数值路径，控制 δ 必须 ≤1e-6。相关性定义为 `abs(<x,z>)/(||x|| ||z||)`，允许最佳复标量而不允许重新对齐时间轴。

用户要求“合理且非数值伪影”的检查由以下**额外工程定义**操作化，均在结果前指定，不替换用户门槛：

- 排除每包 clean 分母能量最低 1%、abs(clean_CIS)>10（100 dB）及首末两个商帧，得到核心 δ；每包四响应中位数的整体 median 必须 ≥0.05。
- 低能量分母和边界各自解释的残余平方能量占比 q95 ≤50%；极端 CIS 的全体占比增加 ≤0.1 个百分点。
- lag1024 周期相干性变化的绝对值 q95 ≤0.05。此周期仅沿用历史条件性 LoRa 假设，不当成严格前导检测或真实 BW/SF 核验。
- 每类按原始行排序分前后各 100 包估计谱形；至少 80% 的源 RX 有序对，其投影差异 cosine≥0.8、半包范数比在 [.5,2]。
- leave-one-TX-out 后投影谱形的相对 L2 改变量 q95 ≤25%。同一 RX 仅一个训练文件，无法检验跨独立文件/会话稳定性，必须披露。
- 六维平滑投影解释去均值原谱差异能量的 median≥50%。
- 先冻结源响应，再比较源留出 RX：最优源 RX+其注册响应相对最优 clean 源 RX 至少减少 10% log-spectrum L2 距离，至少覆盖五台留出 RX 中两台。仅用于关口，不回拟响应。
- 比较自然源 RX 同 TX 平均 CIS 图之间的标准化距离与同 RX 合成平均图的位移，二者 median 比值在 [.1,10]。不同包不配对，不能作为硬件因果真值。

逐包、逐扰动、逐 RX/TX、控制、源谱形、leave-one-TX-out 及自然 CIS 距离全部保存。完整执行两折审计后给 Stop/Go；首折失败也不会触发分类训练。

## V1 和 V2 的分类关口

V0 全部硬关口通过才实现和启动分类训练。V1 恰好五方法×两折×一个 seed=10 次训练。共同使用历史 rank16 FactorizedAuthorCNN、相同唯一源包、20 epoch、Adam lr3e-4/WD1e-4；全部方法零超参数搜索。普通增强 B1 采用 IQ 层独立 complex AWGN，SNR uniform[10,40] dB；该范围有 Ma 原论文依据，不冒充完整 Ma 复现。

为了控制额外视图与计算预算，每个方法每包五个视图：B0/B4 是 clean 副本，B1 是 clean+四噪声视图，B2/B3 是 clean+四个 donor 视图。CE 清洁和增强部分各权重 .5；B3 加权 .25 的 τ=5 平滑最坏 TX×v 风险（减去 log 组数常量）。B4 是 TX×源 RX 分组的普通 multiplicative-weight Group DRO、η=.01。固定平衡 batch，每 TX×RX 一条基包，保证 B3/B4 的所有风险组均覆盖。原始包每 epoch 不重复采样。

以源留出平均 per-RX Macro-F1 选 checkpoint，精确平局取最早 epoch；强基线按 B0/B1/B4 两折平均 F1 最大者固定，平局依次 B0、B1、B4。用户指定全部门槛同时成立：

1. B2−B1 两折平均 F1≥.01，两折分别≥0。
2. B3−最强基线两折平均 F1≥.02，每折≥.005。
3. B3−B2 汇总最差 TX Recall≥.05，平均 F1≥−.005；同时单列每 RX 的最差 TX。
4. 任一 TX/RX（support≥50）的 B3 Recall 对固定最强基线下降不得超过 .10。

另外所有方法须学会源任务（固定全源 probe Accuracy≥.90），不删除失败 seed、不救火重跑。通过后追加另两个 seed，保留原 seed。V2 固定配方，跨 seed 均值仍需满足全部 V1 关口，每 seed 的 B3 相对固定最强基线平均 F1 为正，且各 seed 无严重 TX/RX 损失。通过才冻结后续 epoch 并进入 V3。

## OSU 和后续评价

Shen V3 全十源拟合、四开发 RX 只作冻结后的说明性复核。六台历史锁定 RX 本注册不开放，未来最终评价必须独立明确；不宣称研究史首次盲测。

OSU 每方向分别遵循源域冻结 A → 目标只读纳入审计 B → 固定模型评价 C。单源版本共享六维扰动族、±3 dB 和身份保护算法，只将经验源 RX 差异改为预定义 N(0,.05²) 自然 log 幅度系数，再同比缩小超范围曲线。不得使用 Shen 经验或目标频谱回拟。单源自身也须通过适用 V0 数值/表征关口。

OSU 不改历史窗口参数：1 MS/s、cf32、8192 样本连续块、lag1024 coherence≥.8、每类至少 20 窗、确定性 linspace 最多 200 窗。检查文件字节数整除 8、有限非零信号及元数据，不将条件性周期窗叫严格同步前导。目标不满足冻结纳入标准，则停止该方向并报告，修改前端需要独立协议。不用目标内容修改范围、阈值、归一化、epoch 或模型。历史 G1 结果全部保留。

20k/40k/80k 对称敏感性和 Ma/FAN/GRL 等强基线比较仅在所有前置关口通过后独立登记；本 PoC 不提前启动。V0/V1 阈值仅用于工程筛选，无统计显著性或投稿保证。
