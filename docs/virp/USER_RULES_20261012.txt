我同意按 V0 → B0–B4 两折单 seed 筛选 → 三 seed 确认 → OSU 验证 执行，但建议先将下面三个问题写成正式的、可执行的预登记规则。

尤其是第一个问题，你指出了一个可能直接否定 VIRP-RFFI 第一版方法的理论缺陷：静态平滑幅频响应可能被 CIS 的谱商操作抵消。 这一点必须在训练之前验证，不能通过事后增大扰动强度来掩盖。

## 一、接受 CIS 有效变化检查，并将其设为 V0 的硬性关口

明确答复：接受，而且我建议这是 V0 最高优先级的 Stop/Go 条件。

CIS 的核心是相邻 STFT 时间帧的谱功率比：

\\[ C(k,t)=10\log\_{10} \frac{|X(k,t+1)|^2}{|X(k,t)|^2} \\]

假设接收机引起的响应是静态的，且在 STFT 域满足近似关系：

\\[ Y(k,t)\approx H(k)X(k,t) \\]

那么：

\\[ \frac{|Y(k,t+1)|^2}{|Y(k,t)|^2} \approx \frac{|H(k)|^2|X(k,t+1)|^2} {|H(k)|^2|X(k,t)|^2} \\]

接收机的静态频率响应被约掉。

这意味着我们之前提出的平滑幅频扰动：

\\[ \widetilde X(f)=H\_\theta(f)X(f) \\]

在 IQ 上可能产生明显变化，但经过 CIS 后变化非常弱。

严格来说，全包 FFT 滤波与局部 STFT 不完全可交换，因此不会在所有情况下完全抵消。剩余差异可能来自窗口边界、频点混合、有限记录长度或低能量分母效应。

但这些残余不一定代表有价值的接收机变化。

如果模型主要学习这些人为残余，最后的论文贡献会非常脆弱。

### V0 建议冻结的检查

定义训练源数据上的标准化 CIS 变化：

\\[ \delta(x)= \sqrt{ \frac{1}{HW} \sum\_{k,t} \left( \frac{C(T\_\theta x)\_{k,t}-C(x)\_{k,t}} {\sigma\_{\mathrm{train}}+\epsilon} \right)^2 } \\]

其中 \\(\sigma\_{\mathrm{train}}\\) 只能来自源训练数据，不能使用目标接收机统计。

建议采用下表作为首轮工程筛选门槛，不是物理定律：

| 检查项       | 建议阈值                           | 不满足时       |
| --------- | ------------------------------ | ---------- |
| CIS 标准化变化 | 源包的 median \\(\delta\\) ≥ 0.10 | 停止当前幅频扰动路线 |
| 变化覆盖率     | 至少 80% 源包 \\(\delta\\) ≥ 0.05  | 停止         |
| 变化不能过大    | 95% 分位数 \\(\delta\\) ≤ 1.0     | 检查是否破坏身份信息 |
| 无效数值      | NaN/Inf 比例必须为 0                | 停止         |
| 频谱响应幅度    | 初版每频点增益限制在 ±3 dB               | 超出则不进入正式训练 |
| 信号整体相似性   | IQ 最佳复标量后的归一化相关系数 ≥ 0.98       | 停止或判为不合格扰动 |

这些绝对阈值是保守的实验设计起点，仍需要在 V0 前用源训练数据确认数值定义和量纲。除了绝对门槛，我还要求比较自然源 RX 差异的 CIS 分布，避免扰动虽然达到 0.10，却与真实观测变化完全不在同一范围。

必须加入两个负对照：恒定全频增益（理论上 CIS 基本不变）以及零扰动数值路径（检验计算误差）。

同时单独检查低能量分母、极端 CIS 值占比和受损设备类别，不能只看平均 \\(\delta\\)。

V0 决策

如果平滑幅频扰动不能让 CIS 发生足够、合理且非数值伪影的变化：

停止 VIRP-RFFI 当前第一版，不进入 B0–B4。

不允许在查看结果后继续增大幅频范围、添加 CFO、修改 STFT 或替换扰动族，再将结果算作同一次预登记实验。

还需要修正一个术语：纯幅频修改且保持零相位，不一定对应真实、因果可实现的接收机滤波器。因此 V0 应称为 frequency-response-inspired spectral augmentation，而不是宣称已经模拟真实接收机硬件。真实硬件解释需要另行验证相位与因果性。

## 二、继续条件由现在指定，并在运行前登记

你不需要再自行猜测何谓“有意义”。

我建议区分 V0 物理/表征有效性关口 与 V1 分类性能关口。

### V1：两折、单 seed 的性能筛选

五个方法固定为：

| 方法 | 内容                      |
| -- | ----------------------- |
| B0 | Full CIS + 标准 CE        |
| B1 | Full CIS + 普通增强         |
| B2 | Full CIS + 平滑幅频扰动       |
| B3 | B2 + 发射机条件鲁棒风险          |
| B4 | Full CIS + 普通 Group DRO |

B1 和 B4 必须给予与 B2/B3 相同的模型容量、样本预算、epoch 和公平的源域调参机会。B1 的增强幅度不能故意设得很弱。B4 的风险组定义和每组样本覆盖应在运行前冻结。

### 建议的数值门槛

1

新扰动本身必须有增量价值

B2 相比 B1 的两折平均 Macro-F1 至少提高 1 个百分点，并且两个折均不得下降。

否则无法说明它比普通增强更值得使用。

2

完整候选方法必须超过强基线

B3 相比 B0、B1、B4 中表现最好的方法，两折平均 Macro-F1 至少提高 2 个百分点，且每一折至少提高 0.5 个百分点。

这只是允许进入三 seed 复核的筛选线，不代表统计显著或论文贡献已成立。

3

身份保护模块需要证明必要性

B3 相对 B2，最差发射机 Recall 至少改善 5 个百分点，同时平均 Macro-F1 下降不能超过 0.5 个百分点。

如果只是 B2 已经很强，而 B3 没有额外收益，就不应把类别保护作为第二个创新贡献。

4

不得出现新的严重类别退化

对留出 RX 中至少有 50 个样本的每个发射机类别，若 B3 相比最强基线的 Recall 下降超过 10 个百分点，即触发严重退化警报，不通过筛选。

这条规则专门防止重演 TX36 从 93% 掉到 1% 的情况。

对于最差类别指标，应同时报告每个 RX 的最差类和各 RX 汇总的最差类，避免把不同接收机的结果混在一起掩盖损失。

两折、单 seed 样本量仍然很有限。这些阈值只用于淘汰或允许复验，而不是正式证明性能优势。

另外，必须保证方法选择完全基于源 RX 两折。Shen 四台开发 RX、OSU 目标 RX 的任何结果都不能参与 B0–B4 调参。

建议给预登记文件加入这样的固定说明：

> 当 V0 或 V1 任一硬性条件失败时，当前候选路线停止。不得根据留出 RX 或目标 RX 的反馈调整扰动幅度、风险权重或评价阈值后继续将结果纳入同一确认实验。任何新设计必须独立注册并明确说明此前的负结果。

## 三、OSU 允许做原始信号审计，但我建议严格分离两个权限层级

明确答复：允许审计两台 RX 的原始信号，但不允许使用目标 RX 的内容设计、选择或修改训练方法。

这里必须区分两件事。

### A. 测量协议审计

可以检查原始 IQ 文件是否符合固定采集和处理规则，例如：

- SigMF 标注的采样率、数据类型、样本长度；
- 周期性和候选前导结构是否与预先设定的条件一致；
- 信号是否存在截断、异常值或严重采集损坏；
- 按预先冻结规则计算的有效周期窗口数量。

这些信息可以用于判断数据是否满足实验纳入标准。

### B. 模型研发与选择

不允许依据目标 RX 信号去重新设置幅频扰动范围、频带位置、前导检测阈值、归一化方法或训练 epoch。

例如，如果看到 RX2 某个频率衰减严重，就专门调节增强器模拟该衰减，再声称模型具有未知接收机零样本泛化，这就不成立。

### 我更建议的 OSU 执行协议

阶段 A：只使用当前方向的源 RX

冻结信号解码、前导/周期判定、窗口阈值、增强参数和训练配方。全部来自物理先验和当前方向源训练数据。

阶段 B：在目标 RX 上运行相同的只读审计

只能得到规则是否通过、文件是否有效等审计结果；不允许用目标标签优化方法，也不能修改处理参数。

阶段 C：固定模型评价

如果目标 RX 满足预先定义的纳入规则，按冻结流程评价；如果不满足，停止该方向并报告失败。修改数据协议需要新实验版本。

还要承认一个事实：OSU 两台 RX 已经在前面的 G1 实验中用于评价，所以这不是研究史上完全未触碰的目标域。

未来如在相同数据上修改前端并再次实验，应写为新协议下的后续验证，而不是全新独立盲测。

### OSU 只有一台源 RX 的特殊问题

VIRP 第一版不能在 Shen 上使用多台源接收机学到的经验扰动，而到了 OSU 单源任务时又临时换成另一套未经预登记的增强规则。

我建议现在明确：

- 多源情况：允许从当前训练源 RX 估计类别均衡的谱形差异。
- 单源情况：使用预先固定的平滑幅频扰动族与幅度范围，不能使用目标 RX 差异估计。
- 两种情况共享相同的扰动定义、身份保护目标和训练算法；只允许源域统计估计方式不同，并在论文中明确说明。

如果最后证明只有多源版本有效、单源版本失败，应诚实将方法适用范围限定为多源接收机训练场景。

## 四、最终执行授权与 Stop/Go 顺序

| 顺序 | 阶段     | 允许的操作                             | 进入下一阶段的条件       |
| -- | ------ | --------------------------------- | --------------- |
| 1  | V0     | 原始 IQ、CIS 变化、谱形、前端和数值审计           | 全部硬性检查通过        |
| 2  | V1     | 两折 × B0–B4 × 单 seed，原则上 10 次训练    | 满足四项分类性能门槛      |
| 3  | V2     | 三 seed、源域确认和失败复核                  | 正收益稳定、没有严重类别损失  |
| 4  | V3     | 冻结后 Shen 开发及 OSU 确认               | 检查真正未见 RX 的增量价值 |
| 5  | 论文方法阶段 | 与 Ma、FAN/HSIC、GRL、其他增强和 DRO 做公平比较 | 证明方法优于适用强基线     |

有一个研究决策需要提前接受：

如果 V0 发现平滑幅频扰动几乎被 CIS 完全抵消，我会建议直接停止 VIRP 当前第一版。

这不等于无法再做射频指纹论文，而是说明我们最初假定的输入扰动与现有 CIS 表征不匹配。此时应重新研究接收机变化中哪些成分能够穿过 CIS，并用新的文献比较、物理假设和独立协议确定下一候选方向，而不是偷偷把第一版改成 CFO、IQ 不平衡、时变失真等大杂烩。

因此，三个问题的最终决定是：

1. 接受 V0 的 CIS 有效变化关口，而且不过关就停止训练。
2. 采用上述预先指定的数值阈值，并在看到新实验结果之前冻结；阈值是工程筛选门槛，不是统计证明。
3. 允许 OSU 两台 RX 的只读物理协议审计，但模型开发、增强参数和所有选择规则必须严格源域限定。

我认为这是当前最负责任也最高效的推进方式：V0 可能直接节省全部训练成本；只有 V0 从物理和表征层面成立，再用十次左右的小规模训练判断新方法有没有超越普通增强和 Group DRO 的必要性。
