# B1 实施审核：32作业，16正式模型，未批准执行

目标是反证“同一 Strict CIS 的现有普通训练机制能否消除跨seed反复出现的严重类别退化”，**不以signed delta特定预测器或新pairwise Loss为核心**。D0.5在共享模型折内有信息，但跨CNN转移失败且折0不及绝对混淆；B0支持局部损害可重复，不能提前宣布源损害预测机制具备泛化优势。

可执行的审核入口：`python scripts/prepare_b1_review.py --output <新文件.json>`。已生成 [b1_review_matrix.json](../../configs/d05_b0/b1_review_matrix.json)，逐作业给出源内部划分、参数、组采样、损失、预算和外层隔离断言。此入口**只生成/校验配置**；本轮没有实施B1训练runner，没有新增网络/特殊损失。批准B1后，先依照本矩阵准备四个标准基线runner和数学/数据边界检查，再启动已计入预算的首个pilot。不能称当前已跑通四种模型训练。

## 统一配方

四方法均使用Strict CIS、G1固定缓存、FactorizedAuthorCNN(rank16)、658,314个推理参数、Adam、WD0、clip5、无新增增强。正式2外层RX折×2seed（20261013/14）×4方法=16模型；CE也重新训练，不复用B0的不同batch/采样结果。训练五RX各10类别；每RX×TX每batch2包，batch100，一轮100次更新、20轮共2000次更新，每个包每轮恰好出现一次。四方法使用相同预先保存的batch顺序，初始化逐seed配对，GRL附加head在base初始化后生成，避免改变base初始化RNG。

| 方法 | 冻结标准目标 | 拟检验问题 |
|---|---|---|
| CE | 普通CE，group-balanced batch | 同采样/预算的公平起点 |
| Group DRO | 50个RX×TX group，η0.01，q初值1/50，q∝q·exp(η·group_mean_CE)，归一化；加权group均值求和 | 最差域类别优化是否已经充分控制 |
| GRL | 特征512维后附RX head512→128→5，λ0.1，仅反转特征梯度，RX head按正常CE训练 | 真正RX不变约束的平均与尾部影响 |
| SupCon | CE+0.1标准SupCon；归一化512维feature；τ0.1；同TX全positive、排除self，不加定制对权重或投影网 | 一般类别几何是否已足够 |

正式训练每TX在batch含10个包，标准SupCon每anchor有9个positive，其中8个来自不同RX，无需额外复制/增强；内部4RX训练则有7个positive，其中6个跨RX。共享推理结构；正式GRL增加66,309个仅训练RX-head参数，内部搜索用4RX输出head（66,180附加参数），head类别数只对应拟合RX，不把未见内部验证RX加入RX监督类别。须单报训练参数/计算，不称完全等训练容量。CE/DRO/SupCon不新增特征网络。ArcFace是下一层必要边界对照，但第一批不增加第五方法。

## 公平有限参数选择与真实作业数

不能用外层五RX挑学习率。每个外层拟合五RX中，用固定seed20261015产生一个内部验证RX，其余四RX训练；具体ID在JSON中固定，未参考B0性能挑选。每方法、每折各2个学习率候选（1e−4、3e−4），固定10轮，单一搜索seed20261015；内部固定末轮macro-F1选优，完全平手选较低lr。权重、η、τ本轮固定，不暗中加搜索。scaler只拟合当前4个内部训练RX；正式重拟合5个外层训练RX。

这意味着**16个内部搜索作业 +16个正式作业 =32个新增训练作业、480 model-epochs**。不是仅16次训练。内部batch80（40个group各2包），每轮100次更新；正式batch100，100次更新。每方法相同2-candidate选择预算。源内部只选lr，不选最佳epoch，不能以外层结果补调loss权重或增加seed。任何失败原样保留，不挑掉，不自动重启。日后增加权重范围需所有方法同等预算，并重新审批。

## 成本与停止

B0本机V100每20轮正式作业进程占用94.98–97.48秒。按480轮直接线性外推约0.64GPUh；内部只有8000包，group batch与目标反向传播/验证成本改变，实际不能精确同比。暂估**0.7–2 GPUh，申请2 GPUh总reserved占用上限**（包含搜索、正式、初始化/验证/失败）。第一pilot在32作业内承担计时；若全部矩阵外推超过2小时则保存并更新预算，不能悄悄把固定20轮改成更少。B2/FAN原方法不包含在此估算，不套用小CNN吞吐。

评价固定全部TX/RX/seed：Accuracy、macro-F1、最差RX×TX Recall、10pp严重损失单元、90有向混淆及归一化margin；B1各方法首先对相同Strict CE，不能混入Full输入来归因loss。原Full/Strict B0仅作动机/外部上下文，表分开。不按已观察TX35/36造人工保护规则，失败与不利RX全部公开。比较是否兼顾平均与类别风险，源内部风险榜与未知RX评价严格分开；没有独立盲测时只称历史源池探索。

若普通方法改善最差类并保住平均性能，就停止新pairwise算法必要性的主张。若缺口仍存在，再单独审核ArcFace与作者级B2；B1负结果也不足独自批准新Loss。完成D0.5/B0后当前停下，本文件是具体审核材料，不是启动许可。
