对。我认为你这次提出的思路，比我们过去几轮不断尝试新 Loss、新网络，更接近一篇有说服力的射频指纹方法论文应该采用的研究路线。

但我想再明确一点：第二篇论文的创新，不一定是一个新的神经网络。它完全可以是一种具有物理依据的新信号表示、特征校正方式、预处理方法，或者物理处理与轻量学习模块相结合的算法。

申冠雄的工作之所以值得借鉴，并不只是用了 CIS，而是遵循了一条很清晰的逻辑：

1. 接收信号同时包含发射机硬件特征和无线信道影响。
2. 无线信道会干扰模型学习真正的设备身份。
3. 在一定的准静态信道假设下，可以利用相邻时频帧之间的比值，抵消一部分共同的乘性信道响应。
4. 再用 CNN 等分类器学习处理后的指纹，而不是要求 CNN 自己从大量数据中学会全部信道不变性。

这种先建立信号模型、再推导处理机制、最后验证身份识别的路线，正是我们应该学习的。

不过，CIS、CFO 校正、时频谱商和其他物理预处理现在都已有大量后续研究。2025 年已有利用不同微分谱之间比值消除时变信道影响的方法；2026 年的 TQCD 也已研究通过时频商运算减少信道干扰。不能简单换一种比值公式就称为创新。

## 一、目前最大的问题不是 Shen 数据集太小，而是它被当成了研究问题的来源

Shen 的 20 RX 数据集其实有价值：多种接收机、同一批发射机、完整的 IQ，可以让我们研究跨接收机现象。

但它有三个重要限制：

- 只有十台源训练接收机被用于当前模型开发，其中七台是 RTL-SDR，硬件类型分布并不均衡。
- 已公布的 8192 点信号经过上游处理，完整包起点、部分采集参数及接收链路状态不一定可恢复。
- 只有一个实验体系，无法单独证明某种预处理对 LoRa、WiFi 和不同采集系统都普遍适用。

所以，不是 Shen 数据集让我们做不出创新，而是我们一直基于同一批模型输出观察错误，然后设计算法去修复这些错误，却没有先证明造成错误的信号机制是什么。

之前 B1 的结果就是例子。Group DRO 和 SupCon 有时有效，有时失效；这说明分类边界和优化过程不稳定，但不能直接告诉我们究竟是噪声、接收机滤波、IQ 失衡、相位畸变，还是被抑制的真实设备信息造成的。

接下来应当把研究单位从“分类错误”向前移动一步，转向“信号及特征的失效机制”。

## 二、可以从计算机和信号处理领域借鉴什么？

我认为最值得借鉴的，不是某个最新 Transformer，而是下面三种成熟的研究思想。

| 来源领域         | 值得借鉴的思想                       | 在 RFFI 中的对应问题                   |
| ------------ | ----------------------------- | ------------------------------- |
| 数字信号处理与逆问题   | 先建立观测模型，再分析估计误差、噪声放大和不可辨识性    | CIS、CFO、IQ 失衡等预处理究竟消除了什么，又损失了什么 |
| 计算机视觉与不变表示学习 | 区分任务相关信息与干扰因素，不追求无条件地删除所有变化   | 某些被当作接收机干扰的特征，可能同时包含发射机身份信息     |
| 统计估计与不确定性建模  | 对低可信度观测进行可靠性控制，而不是让所有观测具有相同权重 | 时频谱中某些位置不稳定时，是否应该参与身份判别         |

这里面最重要的是第一项。

我们要寻找的突破口应该像这样：

\\[ \text{已有处理的假设} \rightarrow \text{假设在什么条件下失效} \rightarrow \text{失效造成什么可观测后果} \rightarrow \text{针对性修正} \\]

而不是：

\\[ \text{Accuracy 下降} \rightarrow \text{增加新模块} \rightarrow \text{观察是否上涨} \\]

## 三、结合已有代码，我认为有三个真正值得检查的信号处理问题

注意，下面是待证的研究候选。它们具有物理依据，但还没有被我们证明为当前数据中的主要错误原因。

### 候选 A：CIS 消除乘性信道后，是否引入了加性噪声敏感性？

优先检查

CIS 的重要思想是，相邻时频帧受到近似相同的信道影响，可以通过相除抵消。

理想模型：

\\[ Y_t(f)=H(f)S_t(f) \\]

因此：

\\[ \frac{Y\_{t+1}(f)}{Y_t(f)} = \frac{S\_{t+1}(f)}{S_t(f)} \\]

但是加入噪声：

\\[ Y_t(f)=H(f)S_t(f)+N_t(f) \\]

比值变为：

\\[ \frac{H S\_{t+1}+N\_{t+1}} {H S_t+N_t} \\]

这时信道不能完全抵消，尤其当分母信号能量较低时，噪声可能被明显放大。

这就构成了一个非常自然的研究问题：

> 一种为了消除信道干扰而设计的时频表示，是否在某些接收条件下放大了加性噪声，进而破坏微弱的设备身份特征？

它有两个优点。

首先，问题可以从数学模型推导出来，不依赖某个 CNN 为什么把 TX35 认错。

其次，解决方式可能是一种可靠性受控的谱商估计器，而不需要引入新网络。

例如，借鉴统计信号处理中的正则化逆估计、噪声方差估计和不确定性加权，对低可靠时频区域降低信任程度，同时保留高可靠区域的细微硬件特征。

但已有研究非常接近：

- [Chen 等：微分谱比值方法，2025](https://www.alphaxiv.org/abs/2503.22378) 已利用不同谱差分之间的比值抑制信道影响。
- [TQCD，2026](https://www.sciencedirect.com/science/article/abs/pii/S1874490726001473) 已研究时频商运算和信道解耦。
- [PIR，2026](https://www.sciltp.com/journals/pc/articles/2607004785) 已使用物理理想前导参考与 CIS 残差，并强调数值稳定性。

  [image](https://www.google.com/s2/favicons?domain=https://www.alphaxiv.org\&sz=32)

  alphaXiv

  +2



所以我们不能简单提出“CIS 分母加 epsilon”并宣称创新。

真正可能有价值的缺口，是可靠性估计能否识别那些不应被信任的谱商，同时证明被保留的部分具有发射机判别价值。

现有 VIRP 在一个低分母单元观察到数值敏感性，但还没有证明这种敏感性普遍造成自然跨 RX 错误。因此下一步必须先检查它的实际发生范围。

### 候选 B：接收机 IQ 不平衡是否破坏了 CIS 的信道抵消假设？

这个方向更偏物理信号建模，也更具跨 LoRa/WiFi 的潜力。

通常我们把接收机影响简化为：

\\[ Y(f)=H(f)X(f) \\]

但在存在 IQ 不平衡时，一个常用的广义线性模型是：

\\[ y[n]=a\\,x[n]+b\\,x^\*[n]+w[n] \\]

其中 \\(x^\*[n]\\) 是复共轭信号。

它带来的现象是：接收信号可能包含镜像频率分量，而不只是原始信号乘上一个幅频响应。

这对 CIS 很关键。

如果接收机仅引入乘性响应，谱商有可能抵消它。

但如果还出现与共轭信号相关的镜像泄漏：

\\[ Y_t(f)\approx aX_t(f)+bX_t^\*(-f) \\]

那么前后两帧的比值一般不能直接抵消 \\(a,b\\)。

这就能提出一个更具体的问题：

> 传统乘性不变特征是否忽略了接收机引入的共轭镜像混合，从而留下跨 RX 的残余畸变？

计算机领域可以借鉴复值网络、结构化逆问题和等变表示；信号处理领域则已有广义线性均衡、IQ 失衡估计和镜像抑制技术。

这些都不是新发明。2024 年已有广义线性 IQ 失衡处理研究，2026 年也已有 GAN+RLS 接收机失真补偿方案。

[image](https://www.google.com/s2/favicons?domain=https://harvest.usask.ca\&sz=32)

harvest.usask.ca

+1



它的最大难点是：发射机自身的 IQ 不平衡，也可能正是我们要识别的硬件指纹。

如果盲目把 IQ 不平衡全部消除，就可能连真正的设备身份也删除。

而仅凭接收 IQ，没有参考测量时，发射端与接收端贡献可能不可唯一分解。

因此它值得做的不是“再加一个 IQ 补偿器”，而是研究：

是否存在一种可以验证的、身份保留的镜像失真处理方式？

如果仅靠公开 IQ 无法区分发射端和接收端效应，就必须停止物理归因，不能给它编一个因果解释。

### 候选 C：时频特征的分辨率与设备身份信息之间是否存在可解释的权衡？

不同硬件失真可能表现为不同的时间或频率尺度。

例如：

- 瞬时相位和频率变化；
- 非线性放大引起的频谱变化；
- IQ 镜像；
- 细微的瞬态变化。

固定 STFT 窗长可能突出某类信息、模糊另一类信息。

但多分辨率 CIS、可学习频率选择、注意力特征提取在 2026 年已经有直接先行工作。

所以它的研究空间相对较窄，不能直接把多尺度融合当作第二篇主创新。

## 五、下一步如何实施，避免又走向无意义的实验？

我建议新阶段只做一次信号机制筛选，与之前的分类算法 B1 分开。

M0

先分析现有论文的信号假设

阅读并比较 CIS、TQCD、微分谱比值、PIR、广义线性 IQ 补偿的推导。整理每种方法成立的条件、保留哪些物理特征、在哪些条件下可能失效。

目标是得到两个明确、可以被反证的数学假设，而不是新网络。

M1

只分析原始 IQ 与特征，暂不训练

对 A，先核查低可靠时频区域的占比、自然分布、跨 RX 差异，以及噪声与分母能量的关系。

对 B，先核查接收信号中是否存在能够可靠估计的镜像相关结构，以及这种结构是否与 RX/TX 分类同时相关。

必须设置物理模型成立的合成正对照、负对照和数值稳定性控制。人工扰动只能验证算法性质，不能证明自然接收机失真。

M2

检查是不是现有简单信号处理已经足够

使用冻结模型及输入对照，先检验固定参数的传统正则化、噪声估计或广义线性补偿，是否能够改善特征可靠性，并保留设备可分性。

不根据十台留出 RX 的标签逐个选择预处理参数。也不能以接收机差异缩小，直接代替身份信息得到保留的证据。

M3

如果机制成立，允许最小算法 PoC

这一步不需要再无限做 CPU 审计。可以固定一种候选预处理，使用同架构 CNN、相同训练预算和配对 seed，进行一轮有限训练。

如果传统处理已经足够，停止该算法候选；如果新的处理具有稳定、可解释的增益，才进一步开发论文方法。

这一轮有两个必须特别坚持的原则。

第一，研究机制时不根据某台 RX 上的最终 Accuracy 反向修改预处理。 否则只是把人工调参从 Loss 移到了前端。

第二，不应把一个数学上成立的不变性直接当作更好的射频指纹。 设备分类依赖的恰恰是细微硬件差异。消除接收条件的同时，是否消除了身份线索，始终是需要验证的核心。

## 六、通用性怎么证明，而不是又在 Shen 上做一个特例？

我建议采用两层验证。

第一层：通用信号模型。 先说明方法处理的是什么，例如加性噪声导致的估计不稳定，或共轭镜像混合。只要这个物理模型成立，处理方式原则上就不应该依赖“TX31–40”这些设备编号。

第二层：公开数据跨体制验证。 在 Shen 上开发与验证 LoRa 设置，随后使用 WiSig 的小型 ManyRx 数据作为另一种无线体制的确认来源。

但跨体制不意味着一份 STFT 配方原样复制到所有数据集。WiSig 常用的是 256 点前导 IQ，而 Shen 当前是 8192 点 LoRa IQ，必须说明表示构造的适用条件，不能靠不同参数之间的结果拼出通用性。

最重要的是把开发和确认分开：

\\[ \text{Shen：机制探索、参数开发} \quad\longrightarrow\quad \text{WiSig：冻结方法后的独立验证} \\]

WiSig 官方压缩子集的规模只有 GB 级，和下载完整 OSU 并不相同。等数学机制和第一轮方法 PoC 有支持后，再选择是否需要下载，而不是现在重新准备另一套庞大数据环境。

## 七、我希望我们以后用什么标准来判断一个想法能不能做成论文？

我建议以后每个候选课题都先写清楚四句话。

第一句：已有方法依赖什么假设？

例如，CIS 假设某些相邻时频观测共享近似乘性的信道响应。

第二句：这个假设在什么具体条件下会失效？

例如，加性噪声、低能量分母或非纯乘性的镜像混合。

第三句：这种失效是否真实影响设备身份判别？

必须在真实数据中有可重复证据，不能只靠合成扰动。

第四句：我们能否提出一个比已有处理更合适、而且不破坏身份信息的机制？

这是最后才需要回答的算法设计问题。

满足前两句，只能说明存在理论研究方向；第三句成立，才能说明找到了现实问题；第四句得到强实验支持，才开始接近一篇独立的算法论文。

### 最后的建议

我同意你的研究定位：第二篇应优先寻找“现有射频特征处理在某个明确条件下失效”的通用问题，再借鉴数字信号处理、逆问题、统计估计和表示学习来设计有物理依据的修正机制。

我建议现在暂时封存“类别对 Loss”和“模型选择”两条主创新构想。保留 B1 作为后续分类强基线，但不继续投入优化它们。

先做一个小规模的文献—数学假设对照，优先检查 CIS 在加性噪声下的可靠性边界，同时评估 IQ 共轭镜像混合是否构成一个尚未被现有处理充分解决的问题。两者都不能因为有公式就认定新颖，尤其需要和 2025—2026 年的直接竞争方法比较。

我们的目标不是必须发明一个复杂算法，而是找到一个能说清楚：

“已有信号处理为什么在某类真实接收条件下不够好，我的新处理具体修复了哪项失效，同时保留了哪些发射机身份信息。”

能把这条链条真正建立起来，比再做几十组 Loss 实验更有机会形成一篇有说服力的第二篇论文。
