## 两个可反证假设及界限

A：在共享乘性响应、加性噪声与局部高SNR下，谱商的扰动与分母/分子功率及噪声协方差相关；低可信区域应在自然数据中可测，并与未拟合RX上的身份损害存在跨RX/TX重复关系。若只观察到人工噪声敏感或无有效自然噪声估计，则不能把它确定为自然跨RX错误机制。

B：共轭混合通常破坏纯乘性谱商不变性；但公开IQ是否能识别发射端与接收端贡献是独立问题。若可由不同TX/RX失衡组合产生同一观测，则仅报告合成等价与非圆性统计，不开发声称消除RX失衡而保留TX失衡的补偿器。

## 不根据结果改变的执行细节

- 源集合：b200_mini_1、b210_1、pluto_1、rtl_1/2/3/5/6/7/9；仅 `_train.h5`。复用封存 rows 与原TX31–40标签。所有源输入、模型、代码 SHA 在执行前核验。
- 低分母：分母功率除当前包谱均功率；固定阈值1e-4/1e-2，另报1%分位敏感性，不把固定分位占比当自然发生率。
- 重复残差：1024样点延迟，先估计单包共同相位，以相减后的STFT各频率功率作代理。延迟是继承的研究假设；8192样点不是已证完整原始前导。残差同时包含非重复符号、相位/信道漂移、硬件变化、噪声，不能当纯热噪声。
- M2传统对照一：`log10((|num|²+ν_proxy)/(|den|²+ν_proxy))`，固定乘数1，无系数搜索。两侧正则化避免仅分母 shrink 的不对称偏置。本轮未声称新算法。
- M2传统对照二：从单包非圆性求传统广义线性圆化系数。仅诊断“盲补偿可能删除什么”，非自然RX失衡校准；proper-input假设不成立时不能赋物理解释。
- AWGN：每RX×TX封存位置前20包、40/20dB、2次配对扰动；只验证敏感性，不证明自然机制。
- 数值：复数128基准、complex64与移除1e-12；不静默剪裁/改变epsilon。原始Strict缓存逐包精确重建，冻结identity预测回读历史一致性。
- 统计：同RX×TX内去均值关联，每折/seed独立报告；RX才是泛化单位。10源、7RTL、重复使用的探索池，不称新盲测。训练包上的观察不混入冻结外层身份评估。
- 输入控制可能给冻结网络造成分布变化；性能下降不能独立证明身份已删除，类间/类内特征也只是该固定模型的辅助证据。
