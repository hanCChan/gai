你们在 2,000 个源包上观察到：

- 重复上 chirp 结构非常清晰，1024 点相关相干度中位数达到 0.998882。

## 四、我建议的新研究假设

暂定问题名称：

Correlation-Aware Evidence Accumulation for Reliable LoRa RF Fingerprinting

即“相关性感知的 LoRa 射频指纹证据累积”。

先不提出新网络，也不命名新损失。

定义每个窗口的分类 logits：

\\[ z_t\in\mathbb R^C \\]

传统方法直接累积：

\\[ \bar z_K=\frac{1}{K}\sum\_{t=1}^{K}z_t \\]

它没有显式判断窗口是否重复提供了相同证据。

假设同一录制文件内，连续若干窗口的预测高度相关。如果多个窗口都受到同一个接收条件的影响，那么增加窗口数量，并不一定带来相应数量的新增身份信息。

由此产生一个候选研究问题：

能否只依赖训练阶段的录制会话，学习一个在新日期也可靠的证据累积与停止规则，使模型在不增加误判风险的情况下，减少无效重复观测？

注意，序贯检测、相关性估计和提前停止都是成熟技术。只有它们在 RFFI 的特定失效条件下解决了已有方法尚未处理的问题，才可能构成论文贡献。

### C1 必须输出的诊断

沿用原始文件内的窗口位置，分别分析 \\(K=1,2,4,8,16,32,64,128,256\\)。

但要分清两种采样方式：

- 按录制时间顺序取前 K 个窗口：用于讨论实时累积与决策延迟。
- 在整段录制中均匀抽取 K 个窗口：仅用于离线聚合，不能假装是实时提前停止。

主要输出应包括文件级 Accuracy/Macro-F1 随 K 的变化、错误预测持续长度、同类错误聚集程度、类别 margin 的相关性，以及不同模型各自的聚合增益。

对相关性可以先探索：

\\[ N\_{\mathrm{eff}} \approx \frac{N}{1+2\sum\_{\ell=1}^{L}\rho(\ell)} \\]

但这个有效样本量公式依赖平稳性及相关性估计条件，只能作为诊断近似，不能直接宣称 256 个窗口实际等于几个独立物理发射事件。

而且统计必须按独立录制文件或采集会话汇总，不能把 256 个窗口当作 256 个独立实验。

### C2 应该怎样判断是否值得继续？

我建议同时考虑三个关口。

| 关口    | 继续的必要条件                              |
| ----- | ------------------------------------ |
| 数据有效性 | 窗口顺序、录制会话、标签和源/目标日期对应关系可核验           |
| 问题真实性 | 聚合失效或证据冗余在多个源端录制条件下复现，而非个别 TX 或 seed |
| 方法必要性 | 最强普通融合、校准及现有多包融合方法仍无法处理该失效           |

这里先不规定一个必须提升 5 pp 的数值目标。C0/C1 的任务是验证问题是否存在。

如果走到真正的算法 PoC，可以将“相同文件级错误率下减少平均窗口数量”，或者“相同窗口预算下改善最差采集条件的正确率与校准”作为主要目标，并在看到新方法结果前登记性能和资源门槛。

这种任务定义有一个优点：即使分类准确率接近饱和，仍可能研究可靠性—观测成本之间的关系，而不必强行突破一个已经很高的分类分数。

## 八、除了 C，还有没有其他方向？

有，但我不建议现在同时启动。

另一个值得保留的备选问题是：多源接收机训练的硬件类型覆盖不均衡，是否导致模型在少数硬件家族上出现系统性负迁移？

目前 Shen 的十台源 RX 中有七台 RTL，而 B210、Pluto、B200 mini 各只有一台。跨硬件类型的训练覆盖和评价权重确实存在不均衡问题。

这可能形成数据效率或接收机选择问题，但 Group DRO、接收机对抗学习、多源域泛化和 RIFLE 等已有很接近的研究。仅重新加权 RTL 样本，不足以成为独立新算法。

所以我不会让它与 C 同时消耗训练预算。

## 九、我对现在的研究状态和可发表性的判断

P0 同步路线：停止，不继续投入。

C 多窗口证据可靠性：值得进行一次低成本机制审计。
