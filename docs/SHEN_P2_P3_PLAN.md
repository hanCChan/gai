## P2 输入、编码器和融合分开

E05/E06 只有在 P1 中带外可观测且存在可检验设备信息时作为互补性实验启动。统一使用严格 IB-IQ 与原包独立提取的 OOB 频谱；归一化在掩码之后，不使用被排除的频带能量拟合尺度。默认保护带 12.5 kHz，同时预登记 0、6.25、25 kHz 的敏感性对照，不能选最优保护带后只报告该点。

固定强表示后比较容量匹配 CNN、原 RF-HSTU 和标准 Transformer。分别记录参数量，CNN 宽度搜索需要匹配实际模型而非仅相同 embedding 维度；CIS 作者 CNN 与 1D CNN 架构不同，不能把其增益全部归因于表示。每个对照允许相同数量的学习率/权重衰减候选 [1e-3,3e-4] × [0,1e-4]，相同训练预算、早停、Day2 选模及失败记录规则。

融合组：No-OOB、Concat、标量 Gate、旧 CrossAttn。旧 CrossAttn 保留为历史结构对照；另做主分支严格 IB 的版本。旧 FFT/OOB token 沿全局频率轴，IQ patch 沿时间轴，下标相同不等于物理对齐。旧 positional/chirp embedding 给频率 token 赋时间含义是待排除的历史混杂，不能据此解释机理。

训练组先固定 CE。SupCon/GRL 独立消融；单接收机训练不得启用接收机 GRL。聚合组 [1,2,4,8,16,32] 包只有取得可靠观测组 ID 后实现；当前文件包含多个设备，不能整份 HDF5 投票，也不能把任意跨 session packet 拼成独立观测。

## P3 10/4/6 候选分组

基于已有 `inventory/shen_label_audit_20261011.json` 的训练文件元数据及实际文件名，14 台已有训练接收机每台 8000 包、标签 31–40。候选开发接收机为 b200_1、n210_1、rtl_4、rtl_8；其余十台训练接收机为 b200_mini_1、b210_1、pluto_1、rtl_1、rtl_2、rtl_3、rtl_5、rtl_6、rtl_7、rtl_9。额外六台最终候选只按文件名登记：b200_2、b200_mini_2、b210_2、n210_2、n210_3、pluto_2，当前轮不重新读取其标签、信号或统计量。

这是提议，不是已冻结盲测。b200_1 与 n210_1 是训练中缺席的具体硬件类型，因此开发评估混合了接收机实例变化与硬件类型外推；必须逐类型报告。唯一实例的 b210、mini、pluto 无法同时分配训练和开发。最终名单需要核查既有 OOB 诊断的使用历史、采集条件、接收机类型和真正独立性，再冻结。

开发评估：IB-only、IB+OOB、OOB-only 设备分类、接收机探针、同接收机相近质量 OOB shuffle、频带遮挡/扰动、GRL 与代表性对比学习。shuffle 在开发观测组内匹配质量，不能用最终接收机统计量设置分箱。低探针准确率不能证明表征完全不含接收机信息。

仅在真实未见开发接收机上同时出现 OOB 正收益及普通融合负迁移后，才进入质量感知频带门控开发。对照必须包含普通 Gate+相同增强；KL 带内教师一致性另做消融，不能提前把复杂网络当成既定贡献。

## 决策与统计

P1 单 seed 只能筛选；不能确认互补性、接收机不变性或论文贡献。互补性至少需要 E05/E06 相对强 IB/CIS 的配对结果及三 seed 同方向趋势。五 seed 只量化训练随机性；session 未核验时不按 packet 宣称环境级显著性。配对预测按文件相对路径与 row ID 合并，当前可报告 packet 配对差异但必须标注独立单位不明。外部数据或新采集验证待主方法冻结；本轮不下载 OSU。
