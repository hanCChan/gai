你的担心非常关键，而且我认为它会直接决定第二篇论文有没有足够的学术价值。

如果最后的研究结论只是“申冠雄数据集的 RTL 接收机在某个频率范围内有异常，所以我们设计一个频带过滤器”，那确实太狭窄了，我不建议把它作为第二篇论文的核心贡献。

但这次 P2-A/A7 实验可能指向一个更一般的研究问题：

> 在射频指纹识别中，最容易区分发射机的频谱特征，不一定是跨接收机、跨时间、跨信道最稳定的身份特征。我们能不能让模型自动识别并抑制环境敏感的特征，同时保留真正具有发射机身份辨识能力的特征？

这才是值得研究的方向。

不过我要严格区分三件事：

- 通用的科学问题： 确实存在，有信号模型和已有论文支撑。
- 你们在 P2-A 观察到的现象： 是这个问题的一条潜在线索，但目前只在申冠雄数据集的两个开发接收机上得到证据。
- 你们已经发现了新的通用方法： 目前还没有。要通过跨接收机、跨数据集实验和与最新方法的对比才能成立。

## 一、我重新核查了申冠雄原论文：这套数据确实存在特定采集条件

我查看了 Towards Receiver-Agnostic and Collaborative Radio Frequency Fingerprint Identification 的原始论文，尤其是第 8–9 页的硬件与采集配置。

该论文采用 10 台 LoRa 发射设备、20 台 SDR 接收机，包含 RTL-SDR、N210、B200、B210、Pluto 等六种型号。

原论文明确给出了 LoRa SF7、125 kHz 带宽、868.1 MHz 载频和 1 MHz 接收机采样率。实验使用较为受控的视距采集环境。

[image](https://www.google.com/s2/favicons?domain=https://pureadmin.qub.ac.uk\&sz=32)

pureadmin.qub.ac.uk

+1



这意味着你们过去使用的 Fs=1 MHz、BW=125 kHz、SF=7，并不是随意猜测：它们与申冠雄原论文的配置吻合。 但仍需要核对当前本地 HDF5 是否就是该配置、是否经过重采样或其他预处理。

更重要的是，该数据集只覆盖了特定的发射机、SDR 前端、滤波器和采集环境。

比如你们现在发现：

- Near OOB 在 RTL 上达到 89.27%。
- Strict-IB STFT 在 RTL 上取得显著改善。
- N210 的 Strict-IB STFT 反而比 Full-STFT 差。

这里没有任何证据能够说明所有 LoRa 设备、所有接收机的近带外频谱都有效，也没有证据说明 ±62.5 kHz 就是最佳频带。

频带位置本身可能是数据集相关的。

因此，我会明确放弃“发现某个通用最佳频带”这样的研究主张。

## 二、真正具有通用性的，是接收信号中的混杂机制

射频接收信号可以近似写成：

\\[ X\_{y,r,e}(f) = S_y(f)H\_{\mathrm{TX},y}(f) H\_{\mathrm{channel},e}(f) H\_{\mathrm{RX},r}(f)+N(f) \\]

其中：

- \\(y\\)：发射机身份。
- \\(r\\)：接收机。
- \\(e\\)：日期、位置、信道等环境条件。
- \\(H\_{\mathrm{TX},y}\\)：与发射机硬件有关的特征。
- \\(H\_{\mathrm{RX},r}\\)：接收机硬件的影响。
- \\(H\_{\mathrm{channel},e}\\)：传播信道的影响。

这是简化的线性频域模型；非线性失真、IQ 不平衡和其他接收效应未被完整描述。

它说明一个重要事实：

神经网络观察到的频谱，并不是纯粹的发射机指纹，而是多种因素共同作用的结果。

例如，在训练接收机上，某个频带同时包含发射机信息和接收机特征，模型可能依靠它取得很高准确率；一旦更换接收机，这些特征变化，模型就可能失败。

这是一个跨无线体制都可能出现的机制，而不是某个 RTL 数据文件独有的问题。

但这并不意味着每个频带都可以干净地分离出发射机和接收机贡献。仅凭一台接收机的频谱变化，我们还无法判断究竟是谁造成了异常。

而且，学术界已经明确研究了接收机造成的分布偏移。2025 年 IEEE IoT Journal 的 [Domain Generalization for Cross-Receiver Radio Frequency Fingerprint Identification](https://ieeexplore.ieee.org/document/10742098) 就通过表征解耦处理发射机与接收机因素。

[image](https://www.google.com/s2/favicons?domain=https://ieeexplore.ieee.org\&sz=32)

IEEE Xplore



所以你们真正需要发现的，不是“接收机会影响指纹”这个已知事实，而是已有方法仍未充分解决的一种更具体、可迁移的失效机制及其解决方法。

## 三、检索已有论文后，我发现：这个通用问题已经被观察到，但还没有证明你们提出了新解法

有两项研究特别值得注意。

第一，LoRa 的频谱指纹与跨环境稳定性确实可能发生冲突。

2024 年发表的 LoRa RFFI 综述总结了早期 OOB 研究：FFT 特征在同日识别时可能表现很好，但跨日期、位置或配置变化后仍然出现严重性能下降。也就是说，“频谱有辨识度，不代表它在环境变化后仍然可靠”并不只是你们在 RTL 上偶然看到的现象。&#x20;

[image](https://www.google.com/s2/favicons?domain=https://pmc.ncbi.nlm.nih.gov\&sz=32)

PMC



第二，最新研究已经试图解决相似的问题。

2026 年 8 月发表于 IEEE TIFS 的 Information Bottleneck-Driven Cross-Receiver RF Fingerprinting for Physical-Layer Security 已使用频率感知自适应滤波、双流卷积和信息瓶颈，处理接收机变化引入的冗余信息，并在 WiSig 和 LoRa 数据集上验证。

[image](https://www.google.com/s2/favicons?domain=https://ieeexplore.ieee.org\&sz=32)

IEEE Xplore

+1



这带来一个很重要的结论：

如果我们只是提出“自适应挑选更稳定的频带”，创新性很可能不够。

要进一步发展，必须找出现有频率自适应方法尚未充分解决的问题。例如，区分“有身份辨识力但容易跨接收机失效的频带”和“真正稳定的身份特征”，并用明确的机制约束而非单纯注意力权重来解决。

也就是说，方向可以继续，但需要更精确地定义贡献边界。

## 四、怎样从一个数据集现象变成真正通用的方法？

我认为至少需要完成三个层次的验证。

第一层：同数据集，不同接收机

使用申冠雄数据集的多种接收机，检验异常机制是不是只发生在 RTL-6。重点包括 RTL、N210、B200/B210 和 Pluto。

如果规律只在 RTL-6 出现，研究仍然可能是特定设备诊断，而不是通用方法。

第二层：不同采集团队、不同 LoRa 硬件

使用 [Oregon State University LoRa 数据集](https://research.engr.oregonstate.edu/hamdaoui/datasets)。

OSU 提供 25 台发射机、915 MHz、1 MS/s 的信号数据，涉及不同日期、距离、位置、配置和接收机。这是很适合检验方法是否依赖申冠雄数据采集条件的独立数据来源。

[image](https://www.google.com/s2/favicons?domain=https://research.engr.oregonstate.edu\&sz=32)

research.engr.oregonstate.edu



第三层：不同无线通信体制

使用 [UCLA WiSig 数据集](https://cores.ee.ucla.edu/wisig/overview/)。

WiSig 有 174 台 WiFi 发射机、41 台 USRP 接收机和四次跨月采集，适合进一步检验你的方法是否超越 LoRa。

[image](https://www.google.com/s2/favicons?domain=https://cores.ee.ucla.edu\&sz=32)

CORES Lab - UCLA



这里有个非常重要的实验设计原则：

不同数据集不一定要学出相同的最佳频带，但应当能够使用相同的方法自动识别哪些特征更稳定。

例如：

| 数据集        | 最终有效频率范围 | 新方法的目标      |
| ---------- | -------- | ----------- |
| Shen LoRa  | 待学习      | 自动保留稳定身份信息  |
| OSU LoRa   | 可以不同     | 不修改核心算法仍能工作 |
| WiSig WiFi | 很可能不同    | 对不同无线体制仍有改善 |

这才是真正的算法泛化。

WiSig 常用预处理样本只有 256 点，不能直接把你们 8192 点 LoRa FFT、52×126 STFT 和固定 OOB 定义照搬过去。应保留通用的学习目标，重新构建符合 WiFi 信号特征的前端。

而且，不同数据集的发射机标签并不对应，不能直接用在 Shen 上训练的十分类器去 OSU 测试准确率。应当比较同一学习方法在各自训练接收机上训练、各自未见接收机上评价的结果。

## 五、我更看好的方法，不是固定频带过滤，而是跨环境可靠性约束

假设某个频带 \\(b\\) 的表征为 \\(z_b\\)。

模型应该同时回答两个问题：

问题一：这个特征能不能区分发射机？

\\[ D_b=\operatorname{Discriminability}(z_b,Y) \\]

问题二：同一发射机换了接收机，这个特征还稳定吗？

\\[ V_b= \mathbb E_y\left[ \operatorname{Var}\_{r} \left(\mathbb E[z_b\mid Y=y,R=r]\right) \right] \\]

这里的 \\(V_b\\) 只是一个候选稳定性度量，实际还需要考虑类内分布、信道、采样均衡和表示坍缩等问题。

我们希望保留：

\\[ \boxed{\text{高发射机辨识力}+\text{低跨接收机变化}} \\]

而不是简单保留“分类准确率最高的频带”。

如果后续研究证明，训练源域中的这种发射机条件稳定性能够预测未见接收机的泛化表现，就有机会设计更有针对性的可靠性约束。

但这里存在一个需要解决的科学难点：

如果某个频谱特征既包含有用的发射机信息，又包含接收机相关信息，怎样抑制后者而不损害前者？

这恰好是许多域不变学习方法面临的问题。2026 年 TIFS 的信息瓶颈工作已经讨论了过度对齐可能损伤发射机辨识性，因此我们的新方法必须与它做正面比较，而不是换个损失函数名称就声称创新。

IEEE Signal Processing Society



## 六、我建议把下一轮科研目标修改为这样

不再以“寻找 Shen 数据集的最佳频带”为目标，而是采用下面这个可证伪的研究路线。

| 阶段 | 核心问题                   | 必须获得的证据                   |
| -- | ---------------------- | ------------------------- |
| G1 | 频带辨识性与跨环境稳定性是否存在可重复冲突？ | Shen 多 RX + OSU 复现        |
| G2 | 能否从训练源域预测哪些频谱特征在目标域失效？ | 稳定性指标与未见域性能的关系            |
| G3 | 基于这种关系设计的方法能否减少负迁移？    | 超越固定过滤、GRL、对比学习、现有频率自适应方法 |
| G4 | 方法是否跨数据集成立？            | Shen、OSU，条件允许再加 WiSig     |

如果 G1 不成立，停止继续围绕频带构建新方法。

如果 G1 成立但 G2 不成立，说明我们观察到了现象，却还没有找到能指导模型设计的机制。

只有 G2 和 G3 都成立时，才真正具备形成新方法贡献的条件。

这比直接从 A7 的 24 个百分点收益出发设计复杂网络更严谨，也更能应对审稿人关于数据集针对性和泛化性的质疑。

## 七、对第二篇论文现在应该做出的选择

我认为可以保留两条路线，但先不要固定论文标题。

路线 A：跨接收机的稳定射频指纹表示学习

优先探索

目标是学习保留发射机特征、减少接收机与环境依赖的表示。频带诊断只是发现问题的工具，不是最终论文的全部内容。

路线 B：频谱信息的条件性可靠利用

如果能够证明 OOB 在部分接收机上有用、在另一些接收机上有害，再研究如何利用训练源域可靠地预测这种条件性，而非强制融合。

对于现在的项目，我更偏向路线 A，因为它不要求 OOB 一定有效。即使后来证明完整频谱、近带外和严格 IB 的最佳组合随着接收机变化，研究也可能继续成立。

但目前我们尚未发现一条新的通用规律。 真正已有证据支持的，是接收机、时间与信道会干扰发射机指纹提取；你们的实验揭示了这种干扰在当前数据和模型下的一些具体表现。能否把表现提升为可预测、可控制、可跨数据集复现的机制，正是下一阶段的核心工作。

所以，我会对前一个方案做一个明确调整：

不建议现在围绕 RTL 的 −101.6 kHz 位置继续投入大量模型训练。 可以先做少量无训练的谱图机制诊断，然后尽快将严格 IB、Full、CIS 等强基线带到申冠雄数据集的多个接收机和 OSU 数据集上，先看规律能否复现。

如果无法复现，我们就及时换方向；如果可以复现，再研究如何把这一机制转化为真正超越已有工作的算法。这样第二篇论文才不会被一个数据集的特殊现象限制住。
