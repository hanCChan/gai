# Shen P2-A 完整结果与问题

冻结基线是 `eb4ce2c`，实验分支为 `experiment/shen-p2a`。原 P1 的 32 次运行及已保存预测、曲线、混淆矩阵均经核对保留。主实验按[预登记](shen_p2a/PREREGISTRATION.md)完成 52 次筛选与 56 次确认，共 108 次；诊断后追加的 A7 严格 IB STFT 完成 8 次筛选与 8 次确认。全部结果使用 Day2 开发包，每运行 2000 包，十类 Macro-F1、混淆矩阵、样本 ID 和逐包配对均经独立重算。汇总证据见 [完整归档](../reports/shen_p2a/2026-10-12_p2a_complete/publication_manifest.json)、[主实验报告](../reports/shen_p2a/2026-10-12_p2a_complete/report/REPORT.md)、[A7 报告](../reports/shen_p2a/2026-10-12_p2a_complete/A7_followup/report/REPORT.md)与[融合分支诊断](../reports/shen_p2a/2026-10-12_p2a_complete/A5_branch_diagnosis/REPORT.md)。

## 七个研究问题的结果

1. **RTL 设备 34。** P1 作者 CIS 的三 seed 在 Day1 训练均为 800/800、同日测试均为 200/200，Day2 均为 0/200；重算预测与历史逐包一致。Day2 原始幅度、CFO/SNR 原始元数据和 Spec/CIS 粗统计均改变；CIS 绝对值 99 分位均值没有极端增加，低能分母比例仅小幅升高。最大的描述性特征差异约在假设 −101.6 kHz 的 STFT 位置，位于假设标称 IB 外。这些观测不能确定硬件、信道、采集或标签的因果来源。
2. **Spec、CIS 与容量。** 相同 658,314 参数模型、STFT 几何及预算下，RTL 完整 STFT Spec 三 seed准确率 67.43%±1.03%，CIS 73.52%±3.40%；二者设备 34 召回均为 0%。N210 分别为 98.73%±0.25% 和 99.22%±0.35%。轻量原始 CIS 的 RTL 三 seed 为 78.40%、74.20%、72.65%，设备 34 仍全错。容量缩减或普通 Spec 不能单独修复该异常；rank16 头也改变模型假设空间，不能把此对照称为纯参数量消融。
3. **频带。** 相同频域 RI 坐标与 CNN 下，近带外的三 seed 均值在 N210/RTL 为 86.30%/89.27%，中带外为 47.53%/28.92%，远带外为 56.02%/24.22%。RTL 全 OOB 为 87.22%±5.95%。保护带、归一化、窗的首 seed 敏感性候选全部保留；频带宽度与训练输入统计不同，分类能力不能单独证明真实发射机带外指纹。
4. **简单融合。** 预登记门槛要求同一种 OOB 融合在至少一台接收机三个 seed 的准确率和 Macro-F1 均严格优于单 IB 和对应 IB+IB 容量对照；四种接收机/结构组合全部未通过。RTL 单 IB 平均 88.50%，IB+IB Concat/Gate 为 93.83%/93.92%，IB+OOB Concat/Gate 为 82.50%/76.50%。六个 IB+OOB Gate 的平均门值为 0.999952–0.999997，实际强烈压低主 IB 支路；辅支单独 logit 的答对数量与完整模型相同。不能把 Gate 得分解释成稳定双支互补。
5. **Full/IB 稳定性。** RTL 在相同 2LR×2WD 搜索和 30 epoch 策略下，选定 Full、IB 的三 seed 均值为 94.82%±2.38% 与 88.80%±9.27%；同 seed Full−IB 为 +0.05、+19.30、−1.30 个百分点，排名反转仍存在。高学习率 Full 候选出现隐藏表示塌缩，旧早停影子结果和完整 30 epoch 的差值已单列；表示差异与优化影响尚不能完全分开。
6. **HSTU/CrossAttn。** A5 工程门槛未满足。P2-B 的共享 tokenizer、容量匹配 HSTU/Transformer/CrossAttn 和 P3 的 GRL、代表性 Spec+Siamese/CE+NT-Xent 代码已准备并经合成检查，但未在真实 P2-B/P3 数据上训练，也未自动启动。
7. **P3 协议。** 用户提供的旧 OOB 论文 PDF 明确报告了原六台“盲测”接收机结果；20 台均有研究使用历史。候选 10/4/6 只表示本轮训练、开发、锁定角色，不能称六台是整个研究从未见过的独立最终测试。B200-1 与 N210-1 在候选训练集合里均缺同型号接收机；B200-mini 不等于 B200。具体硬件版本、采集日期/session 和旧执行日志仍缺独立核实材料。

## 诊断后 A7 跟进

因设备 34 的描述性变化出现在标称 IB 外的 STFT 位置，另行注册 A7：先将原始 8192 点 FFT 的 |f|≤62.5 kHz 保留并 IFFT，再生成相同 52×126 Spec/CIS。四份缓存的十类抽样地图与独立重算逐元素相同，被排除的 FFT 频点仅有浮点舍入残差。此实验在看过开发结果后提出，属于探索对照，不是原 108 次预登记或独立盲测。

RTL 严格 IB Spec 三 seed 91.82%±1.43%，设备 34 平均召回 81.00%；相同选定学习率的完整 STFT Spec 为 67.43%±1.03%、设备 34 为 0%，逐 seed 配对改善 +24.05、+24.05、+25.05 个百分点。RTL 严格 IB CIS 为 94.00%±1.95%、设备 34 平均召回 87.33%，但它选择 lr=.001，而完整 STFT CIS 选择 lr=.0003，其差异同时包含筛选配置影响。N210 的严格 IB Spec/CIS 为 94.38%/95.73%，低于完整 STFT 的 98.73%/99.22%。投影改变有限长度波形，且 train-only 标准化分别重新估计，因此功能性改善仍不能唯一归因于物理 OOB 信息。
