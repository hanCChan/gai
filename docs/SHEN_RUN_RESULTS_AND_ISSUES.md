## 发现的问题与已处理事项

- **优化停滞明显。** lr=1e-3时N210严格IB只有10%，RTL Full IQ只有10.35%；统一增加lr=3e-4后分别达到90.65%、92.85%。旧弱结果完整保留，不能用它们宣称带内缺少设备信息。

- **CIS并非在两台都最强。** N210 CIS首筛99.85%，RTL CIS首筛81.50%，RTL三seed平均79.50%（Macro-F1 0.7512）。RTL模型训练接近100%时Day2表现仍较低、后期下降，存在过拟合/跨日期泛化问题。当前CE/Adam无作者的完整增强/训练目标，不声称复现原论文性能。

- **模型容量尚不匹配。** IQ/IB/OOB使用完全同结构659,370参数CNN；CIS作者结构13,442,954参数。CIS增益不能全部归因于表示。P2容量对照尚未运行。

- **OOB可观测且有分类线索，但互补性未证明。** OOB-only首筛N21075.60%、RTL88.90%，都低于对应已调参IB。还没有E05/E06融合及真正未见接收机的负迁移证据，当前不足以支持可靠性门控创新。默认保护带下Day2带外能量中位占比约0.0891%/0.1143%；改变保护带能量明显下降，泄漏/滤波/噪声仍可能混杂。

- **CIS端到端吞吐受预处理影响。** 记录分别计模型forward和整个加载/预处理管线；两者有明显差距，GPU瞬时利用率低。需要CPU/STFT与I/O剖析，不能仅按forward速度宣称系统成本。

- **首轮smoke有三个失败记录。** 严格CUDA确定性不支持adaptive pooling backward；已改为形状等价固定AvgPool1d(8)，四卡八组真实Day1小batch检查全部通过。失败日志保留于p0/four_gpu_smoke。

- **发布可复现性修正。** 原工作区训练配置依赖未入仓库的inventory协议，且预登记的静态复验配置尚未反映实际所选lr。发布版已捆绑字节相同的冻结协议并更新全部16个复验配置；审计baseline/ref可显式指定。训练中的实际配置一直正确，未重启训练或改变其配方。

- **数据溯源和外部泛化仍有限。** Fs=1MHz、BW=125kHz为文献假设；实际日期/session/原包身份及既有OOB诊断接收机重叠仍未确认。不能把两台分别训练称为零样本跨接收机。Day3–4及最终六台未读取，P2/P3仅有方案/配置。
