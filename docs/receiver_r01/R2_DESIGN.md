# R2 机制候选：多源模拟部署下的有限更新风险约束

本文件只有数学设计，**没有授权或启动 R2 拟合**。它不是已证明原创算法。R0/R1 完整结果与 source-only 探针是后续决策依据；有限小批次负作用不直接证明对真实未知 RX 的预测或因果机制。

## 先解决发现的可复核性

首先复用本轮所有冻结 checkpoint，拟定一个后续独立授权的诊断：在当前拟合源 RX 内拆分 meta-train、多个 meta-held RX 及每个留RX的两个不相交 packet 集合。训练步仅在 meta-train 集做梯度；留RX A集估计更新前后损失，B集核验同一更新的风险重测。诊断不得看内部10RX或Shen外层RX后选择阈值。

按RX、日期、seed汇报：(1)“源有益、留域有害”的重复性及其超过包抽样噪声的幅度；(2)负梯度内积对有限步长损失增加的解释量；(3)风险量能否预测后续固定轨迹在另一个源留RX上的恶化；(4)梯度步和Adam实际方向、训练dropout与eval-mode的差别。模型自身不充分收敛时，先承认配方问题。三个seed、小批次探针不够给这些问题肯定答案。

## V0：标准 MLDG

`theta' = theta - alpha * grad L_A(theta)`；优化`(L_A(theta)+L_B(theta'))/2`。保留本轮精确二阶实现作为V0，所有系数、骨干、源内选参和seed另行冻结。不得改名为原创。

## V1：对多个留环境的实际有限更新作可靠性约束

候选方向`u0`来自标准MLDG优化器。使用多个当前源留RX的独立风险packet，定义

`Delta_r(u) = mean_t [ell_(r,t)(theta - eta*u) - ell_(r,t)(theta)]`。

拟议受约束方向问题：

`min_u <g_A,u> + lambda/2 * ||u-u0||^2`

`subject to Risk_RX({Delta_r(u)}) <= tau_RX`。

这只是结构候选，不确定最终Risk_RX是最大值、上分位/CVaR还是含抽样误差的上界。本轮不搜索lambda/tau，不拟合方向控制器。所有这些选择须在下一轮冻结的有限源内范围完成；不能从当前内部成绩反推超参数。若多RX极端冲突，应记录不可行/缩步，不能隐藏被拒绝的更新。

一个可实现的最低复杂度控制是对固定MLDG候选方向作有限、预登记的步长回溯，仅使用模拟留RX损失反馈选择是否接受。这与信赖域、线搜索、受约束优化和DRO有显著重叠，**不能单凭“更新可靠性”名称声称原创**。应将它作为验证必要性的候选，先比较“同成本降低LR”“普通源验证早停”“更大meta-held批次”等控制，识别是否只是优化配方收益。任何正式模型及V1数学定义必须在新授权中具体冻结，不能把此开放候选文件当拟合许可证。

为何标准方法可能不完全覆盖：MLDG优化留域平均，不保证每RX在有限步下非恶化；PCGrad控制当前一阶任务内积，不直接检查优化器实际有限更新及抽样不确定性；Fishr约束梯度方差，不实施这类逐步接受检验；Group DRO优化高损失组，绝对高损失与正向更新伤害不是同一量。**这些是形式差别，不是已证明优势**。上述方法均可产生类似鲁棒效果，必须实际公平消融后判断是否存在独立贡献。

二阶需求：沿用V0精确MLDG需二阶。有限更新接受检验只需额外前向；若直接微分Delta_r约束，计算量视方向参数化而定，不能笼统承诺一阶低成本。候选方向若来自Adam，必须保存/恢复参数和优化器状态，不能用SGD探针冒充实际Adam步。推理时保持原backbone，无额外模块。

成本：K个留RX风险批次和M个固定回溯候选增加约K×M次推理；可顺序评估，额外显存包含参数/优化器快照与风险批次。拟合前必须在合成及首个已计入矩阵的真实作业测时间和峰值显存，明确保存全部候选、拒绝次数及预算，不引用本轮轻量CE速度替代计时。

## V2：只在V1平均改善且仍有可重复身份尾部伤害时开发

定义`Delta_(r,t)(u)`来自当前源留RX/TX损失差，不能手工指定历史TX35/TX36或旧D0.5类别对。仅在V1总体泛化重复改善而真实存在剩余尾部退化后，才引入身份风险约束（如CVaR类条件Delta）。需分别与RX×TX Group DRO、绝对损失CVaR、类条件鲁棒优化对照；将负作用差分换个名字不构成新颖性。

预期消融需区分：标准V0；只增加留RX测量而不控制；同预算LR/样本数控制；V1只控制RX风险；V2尾部控制；仅尾部控制。多seed完整配对、有限共同搜索、全部失败候选公开，不能用每个版本第一个seed结果决定是否换seed。最多三次受控版本迭代，不无限加模块。

## 后续批准所需的具体材料

完整R0/R1报告已足够强基线时，先保留它们；若当前剩余问题仅是有限训练/选参，不强行开展新模块。若仍有跨数据集一致的可重复更新风险，则下一轮必须提交固定风险估计式、具体方向/接受规则、阈值和步长有限范围、所有版本/seed/消融作业清单和实测预算。创新性同时核查MLDG、Fishr、PCGrad、Group DRO/CVaR、信赖域和约束多目标方法。RIEI/DRIFT等RFFI先行方法也必须在发表级协议下对照，当前未实跑不能宣称超越。

本轮结束后保持 R1 停止，不使用剩余7小时预算开展这些训练或打开WiSig最终RX/最后日期/等化版。
