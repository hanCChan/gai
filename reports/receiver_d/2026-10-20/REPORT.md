## 1. 开始前的代码发现（改变了 D1 要回答的问题）

1. **L0 全量实际用的是 r1 代码**（`scripts/interaction_l0/physics.py` sha 5c42d2…），不是审稿意见引用的 v0 全带循环滤波。
   r1 `reshape_tones` 只在描述子窗口（样本 20–179）内乘 20 点 DFT 增益，样本 0–19 与 180–255 不滤波，再整体缩放。
   其"音调误差 0.0"是**构造性**的（在测量域施加），波形是分段的，不是任何 LTI 接收机的输出。
2. 真正的 LTI 滤波（整包线性卷积 FIR，零相位/最小相位）在真实包上**无法精确实现**任意 12 音调形状变化：约 ⅓ 的 STF 音调比包均值低 >13 dB（频率选择性凹口），
   且 STF 在 ~180–190 样本结束；在完美周期信号上 FIR 误差 ~1e-15（`test_rxphys.py`），在真实包上 0.25–0.35，误差集中在凹口音调。
   因此 D1 对同一请求变化比较四种实现：`r1_segment`（L0）、`v0_circular`（被批评的旧代码）、`fir_zero`（主臂）、`fir_min`。
3. **作废的首轮**：首轮 D1 中 link/TX "匹配强度"对照未做范数匹配（实现 bug），已修正后重跑（d1b，即本报告数据）。修正只影响 Q_link_dir / Q_tx_dir（非门槛量）。
   r1 实现下的全套对照（§2.4 稳健性）是在看到首轮结果后加入的，**属事后稳健性检查**，不改变冻结判定。

### 2.5 解释力（R7）与"移植"（R8）

- 源域敏感度与内部未见日期 RX 精度（18 official）：RX 互换 ρ −0.96，随机-cov −0.97，倾斜 −0.96，最小相位 −0.98，同单元日漂 −0.89；源精度 +0.35。
  **任何频谱方向的敏感度都同样能预测**——预测信号是"普遍频谱敏感度"，不是 RX 特异的。seed 内（n=6）：RX −0.77/−0.77/−0.43，随机-cov −0.83/−0.83/−0.43。仍受 3 个 seed 簇混杂，需 E0。
- 越"真实"的反事实越伤：仅 RX 主效应 0.360 → 整个单元（含 link）0.496 → +CFO 0.500 → 真实包形状重贴到伙伴 RX 0.546（其音调形状 76% 最近邻就是伙伴 RX 的真实单元）。
  真实的 (TX t, RX r') 包本身被正确分类 ~93%，所以**12 音调幅度不是模型所读"接收条件"的充分统计量**：只改幅度而不改相位/LTF/时域其余部分，得到的是模型从未见过的组合。CFO 无关（+0.004）。
- 训练时长：21 个 WiSig checkpoint 的选中 epoch 为 92–100/100——**模型未收敛**，D1 的全部敏感度结论都建立在未收敛模型上（E 阶段第一项）。

- 这些设备对在**每一台** RX 上都是最易混的对（0↔1、2↔3、1→4、7↔8、9→8）：Pluto 是它们身份间隔被压垮的地方（输入带内对间距为源域的 0.65–0.93）。
- 硬件：Pluto AD9363、B200mini AD9364（SWAD 在其上 +3.5）、B210 AD9361（在 fold 0 训练集中）——同属 AD936x，"未见硬件家族"不能单独解释 Pluto。

跨 10 台 RX（每台恰为一次外部，n=10，探索性，置换 p）：

| x → y | ρ | p | 去掉 Pluto（n=9） |
|---|---:|---:|---|
| 最近源距离 → CE 错误率 | 0.79 | 0.008 | 0.72（p 0.036） |

- "RX 偏移大 ↔ 错误多"：成立于最近源距离与类结构畸变，不成立于整体 d_RX。
- "SWAD 是否主要损害某些设备对"：是（见上）。
- "是否存在同样偏离却不退化的反例"：**无法检验**——Pluto 是唯一极端值，没有第二台同等偏离的 RX；SWAD 失败与 RX 偏移的关联只靠一台 RX，**不得推广**。

**塌缩方向是否由公共接收机偏移决定？否。** 最近原型塌缩分数 s(u→w)：不用标签的公共偏移对 90 个有序对的混淆率 ρ = 0.006（10 台合并），且每台 RX 最大值 0.19–0.58 < 1；含 TX 特异（link）分量时 ρ = 0.31。
Shen 的跨 RX 错误由**少数天生相近设备对上的 TX 特异畸变**驱动，而非公共偏移。

## 5. 根因判断（哪些被支持、哪些没有）

**支持：**
1. WiSig 跨 RX 脆弱性 = **对前导码频谱形状的普遍过敏感**，不是接收机特异的捷径：同强度下真实 RX 方向 ≤ 随机方向，且与该接收机自身日间漂移同量级；其大小主要随 seed 变化，并预测未见 RX 精度。
2. **接收机变化与身份轴对齐**（WiSig，§alignment）：源 RX 差异 95.8% 落在一条轴上（−7.5…−3.75 MHz 与上半带的功率不对称），该轴承载 **34.6%** 的 TX 身份能量，随机方向基线 8.2%（p95 18.8%，p < 5×10⁻⁵）。
   任何沿这条轴读身份的网络都必然依赖接收机；真正对接收机不变的身份表示必须放弃这部分信息——这是"身份保持"的可量化代价。
3. 12 音调幅度不是模型所读接收条件的充分统计量（越完整的幅度移植越伤）。
4. Shen：CIS 已去除大部分接收机主效应；残留失败 = 天生相近设备对在最偏离的接收机上单向塌缩，由 TX 特异畸变驱动，SWAD 加剧、MLDG/GroupDRO 缓解。

**不支持 / 不能说：**
- "RX 硬件频响是主因"——否（§2.3）。"TX×RX 交互不重要"——不能说（Shen 中 TX 特异分量才解释塌缩方向）。
- "频响外推失败是普遍机制"——只有一台 Pluto。
- 预测子可用于选模——尚未在独立 seed 上验证；且 D1 模型未收敛。

## 6. 下一步研究决定（需另行批准；本轮未运行任何训练）

1. **E-pre 收敛复核**（WiSig official CE，300 epoch，1 seed，约 0.1 GPUh）：选中 epoch 是否仍贴上限；在收敛 checkpoint 上重跑 D1（0.03 GPUh），确认"普遍敏感"不是欠训练产物。
2. **E0 选模信号验证**：16 个 CE 运行 = 4 初始化 × 4 数据顺序（独立设置），收敛后 epoch。预先冻结规则：选源域频谱敏感度（随机 LTI 扰动、源域标定幅度）最低者；与源验证 CE、合法源 RX 留一选模比较实际未见 RX 精度；分别检验初始化内与顺序内的相关。约 1.6 GPUh。
3. **E1 方法 PoC（V0–V4 改版，WiSig 同一编码器，3 个独立 seed）**：全部扰动用整包物理 FIR（零/最小相位混合），幅度只由源域标定（源 RX 对距离中位数 ~1.9、日漂 ~0.7–2.0）。
   V0 CE；V1 各向同性随机频谱扰动；V2 只沿源 RX 差协方差（与身份对齐的扰动子空间）；V3 = V2 + KL 一致性；V4 = V3 + 沿 RX 主轴的有界外推（上限 = 源域最大 RX 对距离）。
   预注册假设：H1 V1 ≈ V2（D1 的 GENERIC 先验）；H2 V2 的源身份损失小于 V1；H3 KL 有增益；V4 若下降则不进入最终方法。报告参数量、增强剂量、额外计算、源域选参规则。约 2–3 GPUh。
4. Shen：不在 CIS 行上直接加模板。缓存中存在 `iq.npy`（本轮未读取）；若要跨数据集验证同一物理操作，需单独批准读取 IQ，在 IQ 层施加 FIR 后重新经过 Strict CIS 前端。
5. 建议总预算上限 4 reserved GPUh；超出先停。

## 7. 竞争方法

逐篇摘录与对比见 `docs/receiver_d/LITERATURE_D.md`（本地 arXiv 全文；Soltani 2020 与 TCCN 2026 两篇因网络受限**未读**，未对其内容作任何断言）。

### 7.1 结论

- **KL/一致性损失不是贡献**：CRODA-ST（arXiv 2607.02567）已在跨接收机 RFFI 上用 VAT-KL + 接收机对抗分支（作者自承扰动"not a calibrated physical-noise model"）；Ma et al. 用同一 TX 经两台真实 RX 的 NT-Xent；MASF 用跨域对称 KL。
- **随机 LTI/FIR 增强 ≈ 信道增强**（抽头延迟线信道本身就是随机 FIR；Shen、Ma 以及引用文献所述的 Soltani）；特征层按协方差标定的风格对齐有 ConstStyle。
  **未见先例**：用实测源接收机/日期响应标定的输入层增强（WiSig 2022 将其列为开放问题），以及输入层身份保持约束。但 D1 本身削弱了前者的价值（随机与真实同样伤，真实 RX 方向单位最不伤）；在 Shen CIS 上几乎无作用（CIS 已抵消静态 LTI 响应）。
- **源域敏感度选模在 RFFI 无先例**（所有论文都在源验证上选模）；D'Amour（Underspecification）显示压力测试在同 seed 集成内相关很弱。要成立，必须证明簇内相关，并在选模遗憾上胜过合法源 RX 留一与简单噪声/梯度敏感度代理。
- **真正新的内容**：同强度真实 vs 随机的反事实审计；接收机轴与 TX 身份轴重合（35% vs 8%）——这与 SD-RXA、RIEI、Ma 及 division 类方法的明示假设（接收机效应可与身份分离）相矛盾；同接收机日漂与换接收机同量级；Shen 近邻设备对单向塌缩。
- **审稿人必然要求的最低基线**：ERM + 已发表范围的信道增强；同强度各向同性/倾斜/协方差/接收机移植/日漂增强；Shen 梯度反转法与 GAN-RXA；GroupDRO、MLDG、MASF、CIDG、SWAD；MixStyle、ConstStyle；固定不变前端（相邻音调比/高阶差分；WiSig 等化版若解封）；VAT/AugMix（对照一致性）。

### 7.2 对论文定位的含义

最可能形成一区贡献的不是"又一个增强 + 一致性"，而是**可证伪的诊断框架 + 由它推出的约束**：
(i) 同强度反事实审计说明跨 RX 脆弱性是普遍频谱敏感而非接收机捷径；(ii) 接收机–身份轴重合给出"接收机不变性必然损失的身份信息"的可量化下界；
(iii) 若 E0 成立，源域敏感度成为无目标数据的选模/早停信号。方法部分（E1）只有在 V2/V3 稳定优于上述基线时才写成方法贡献，否则论文以 (i)–(iii) 为主体、方法为对照。
