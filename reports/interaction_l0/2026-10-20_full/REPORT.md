# L0 完整诊断与本地 R0/R1 复现报告（2026-10-20）

北京时间 2026-10-20。本报告包含两部分，全部在本机（4×V100）完成，无一次失败或重试：

1. **本地 R0/R1 复现**：原服务器释放后，冻结的 WiSig 作业（与已发布注册表逐字节一致）加上本地重建 Shen 缓存后的 Shen 作业，在本机重新拟合与评价。
2. **L0 完整诊断**（4 分片全量，21 个作业 = 18 个 WiSig official + 3 个 WiSig resnet）：对"TX×RX 交互捷径"假说的判定输出，以及对跨 RX 失败的物理解释证据。

## 0. 结论速览（本轮判断）

| 判定 | 结果 |
|---|---|
| S（统计关联）：种子内 link_ratio 与未见 RX 精度部分相关 | **通过**（partial rho −0.60；逐种子 rho −0.94 / −0.54 / −0.49） |
| I（干预擦除）：线性擦除 link/rx/cond 子空间能改善未见 RX | **不通过**（frozen −1~−2.6pp，refit ≈0；`artifact_flag=True`） |
| 交互捷径假说总判定 | **INCONCLUSIVE（不成立为可操作机制）** |
| H-CFO（频偏主导未见 RX 失败） | **UNSUPPORTED**（CFO 干预掉点 <2.8pp；CFO 最近邻规则内部未见精度 23.9%） |
| 主导物理量 | **RX 主效应音调响应**：`tone_rx_swap` 掉点 37.8pp ≈ `tone_link_swap` 40.5pp，远超 `tone_tx_swap` 15.1pp；`moved_to_target` ≈ 0.03 |
| 源域可测的未见 RX 预测子 | `tone_rx_swap` 翻转率与未见 RX 精度 rho = **−0.96**（18 个 official 作业）；`feat_link_ratio` rho = −0.90 |
| 硬件族解释 | **不成立**：内部 N210（与 9 台源 N210 同型号）见日期 55.9–59.8%，源 N210 见日期 95.4% |
| 全局种子因子 | 种子主效应 sd 12.28pp **> RX 主效应 sd 6.99pp**（方法折叠后，18 作业 × 10 RX） |

**研究含义**：跨 RX 失败的主轴是"网络把 RX 的 STF 音调响应编码进了指纹"，是 **RX 主效应**而非链路特异交互；CFO 与 SNR 不是主因；线性擦除救不回来（说明依赖是非线性的或已纠缠）。交互惩罚类方法（LIS）降级为消融臂。下一阶段的算法方向为**反事实 RX 响应重采样（CRR）**与**源域可测的反事实敏感度作为 target-free 模型/种子选择器**——均需另行批准后执行。

关键观察：

- **种子因子主导**：所有方法在同一种子上同涨同跌（种子方法均值 35.5 / 65.3 / 46.7%）。SWAD−CE 配对差 +2.7 / −12.1 / −5.8pp，MLDG(rx+date)−CE +4.6 / −4.2 / −2.1pp——**没有任何方法在 3 个种子里稳定占优**，与 2026-10-13 服务器结果的结论一致。
- **不是硬件族问题**：内部 N210（rx9/11/27，与 9/14 台源 RX 同型号）见日期 55.9/59.8/56.9%、未见日期 54.8/55.3/52.0%；而源 N210 见日期均值 95.4%。同型号跨 RX 仍有 ~40pp 落差。
- 概率平均集成（同方法 3 种子）把 CE 从 51.9% 提到 **61.8%**（事后 oracle 单模型上限 71.9%），错误 Jaccard 中位数 0.478——种子间错误高度重叠但不完全。

### 1.4 与已发布（2026-10-13 服务器）结果的一致性

同口径比较（WiSig official internal_unseen_date）：服务器 CE 48.01±10.44、MLDG(rx+date) 51.55±17.20；本机 CE 51.91、MLDG(rx+date) 51.34。均值差在种子间方差的量级内，方向性结论（方法无稳定优势、seed 因子主导、RX 最差 Recall 个位数）完全复现。数值不逐位一致的原因：不同 GPU/环境的非确定性核与不同初始数据顺序；这不影响本轮判定，因为判定只依赖本机内部的配对比较。

## 2. L0 完整诊断（reports/interaction_l0/2026-10-20_full/）

4 分片全量，21 作业，reserved 0.081 GPUh，墙峰 82s；`manifest.json` 的 12 个代码 SHA 与本提交中的 `scripts/interaction_l0/` 完全一致；全部产物 SHA256 见 `PUBLIC_ARTIFACT_SHA256.json`。

### 2.1 无模型物理图谱（atlas）

源池方差分解（ANOVA 份额，source_all）：

| 描述量 | TX 份额 | RX 份额 | 链路(交互) 份额 |
|---|---:|---:|---:|
| CFO | 0.18 | 0.59 | 0.23 |
| SNR 代理 | 0.54 | 0.22 | 0.24 |
| 12 音调谱形 | 0.04 | **0.63** | 0.34 |

音调谱形的 RX 主效应份额在源池与内部 RX 池一致（0.66/0.62），链路份额稳定在 ~0.33——**交互在输入物理量里存在但不是主导**。硬件混杂记录在案（源 RX：9 N210/4 B210/1 X310；同型号与异型号 RX 对的平均距离几乎相同 14.4/14.1 m，ρ=0.05）。

### 2.2 统计臂 S（通过）

- 18 个 official 作业内，种子内 `feat_link_ratio` 与未见 RX 精度的偏相关（控制 `acc_source`）= **−0.60**（规则阈值 −0.40）。
- 逐种子 rho：−0.94（seed13）/ −0.54（seed14）/ −0.49（seed15），3/3 为负（阈值 2/3）。

### 2.3 干预臂 I（不通过）——线性擦除无效

| 擦除目标 | frozen 未见 RX 中位变化 | refit 后 | 同秩扰动强度 (k=8) |
|---|---:|---:|---|
| link 子空间 | −2.22pp | +0.07pp | 链路能量保留 0.63 |
| rx 子空间 | −2.64pp | −0.12pp | RX 能量保留 0.23 |
| cond（条件） | −1.15pp | +0.19pp | — |
| random（对照） | −1.45pp | +0.03pp | — |

擦除 link/rx 都**掉点**，且不比擦同维随机方向好多少；重拟合 9 个小头后增益归零。`I_pass=False`，`artifact_flag=True`（source 掉点 2.7pp 超过 2.0 阈值）。**结论：依赖已线性纠缠在特征里，事后线性手术不构成可用机制。**

### 2.4 物理干预（关键新证据）

对冻结模型做输入物理量干预（official 18 作业中位数；干预"请求 vs 实测"逐项验证见 `intervention_validation.csv`，音调干预 RMS 误差 0.0）：

| 干预 | 精度掉点 (pp) | 预测翻转率 | 移到目标 TX 率 |
|---|---:|---:|---:|
| **tone_link_swap**（换成另一链路的谱形） | 40.5 | 0.460 | NaN |
| **tone_rx_swap**（只换 RX 的 STF 响应） | **37.8** | 0.441 | NaN |
| tone_tx_swap（只换 TX 的谱偏移） | 15.1 | 0.196 | 0.028 |
| snr_link_swap | 3.2 | 0.037 | — |
| cfo_rx ±1sd / ±2sd | 1.2 / 2.7 | 0.06 / 0.08 | — |
| cfo_tx_swap | 0.7 | 0.042 | 0.012 |

判定：

- **`tone_rx_swap ≈ tone_link_swap`**（37.8 vs 40.5pp）：决定性的音调信息是 **RX 的主效应响应**，不是链路特异的交互分量。这与图谱中 RX 份额 0.63 一致。
- `tone_tx_swap` 掉点小且 `moved_to_target`≈0.03：模型用的不是"TX 谱签名"这种可转移的量。
- **H-CFO 不成立**：CFO 平移 ±2sd（±37 kHz）只掉 ~2-2.7pp；"CFO 最近邻"规则在内部未见日期上只有 23.9% 精度；CFO 交换 TX 几乎不动预测。
- **H-SNR 不成立**：SNR 交换只 3.2pp（且 47% 的目标 SNR 不可达，证据强度有限，如实标注）。
- 音调最近邻规则本身（10% 精度）远低于 CNN（44-52%），说明网络用音调信息的方式不是最近邻——但**音调的 RX 响应仍是其未见 RX 行为的主控量**。

### 2.5 源域可测预测子（算法出口）

只看源域即可计算的量与未见 RX 精度的相关（18 个 official 作业）：

| 预测子 | Spearman rho | 说明 |
|---|---:|---|
| `tone_rx_swap` 翻转率（源域上做干预） | **−0.96** | 反事实敏感度 |
| `feat_link_ratio`（特征谱的链路份额） | −0.90 | 与 S 臂同源 |
| `acc_source` | +0.07 (n.s.) | 源精度不预测泛化 |

**但**：3 个种子只是 3 个聚类点（种子方法均值 35.5/65.3/46.7%），rho 的置信区间不可信；**必须在 ≥16 种子上验证后才能当选择器用**（计划 E0）。

### 2.6 L0 结论与下一步（均需批准）

1. **交互捷径作为机制：INCONCLUSIVE**。S 有关联，但 I 失败 + 物理干预指向 RX 主效应 → "交互"更可能是 RX 主效应在有限采样下的表观混合。
2. **CRR（反事实接收机响应重采样）**：在源单元上做 TX×RX 两路分解，交换/外推 RX 效应 b_r 生成反事实输入，CE 双份 + 一致性 KL 训练（计划 E1，与 division、随机倾斜对照）。
3. **反事实敏感度选择器**：用源域 `tone_rx_swap` 翻转率做 target-free 的模型/种子选择（计划 E0：16 种子验证）。
4. **LIS（交互惩罚）降级为消融臂**。
5. 已知的 L0 代码缺口（本轮如实记录）：`run_l0.py` 无 dataset 过滤；方向在 `source`（held 40）上估计且源身份在同一池报告——E0/E1 前修复。
